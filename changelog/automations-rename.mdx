Scheduled Tasks are now called **Automations**. The name is the only thing that changed — every scheduled and one-time task you already have keeps running exactly as before, in the same place.

## What changed

- **Scheduled Tasks** is now **Automations** across the web app and docs.
- Find them under **Automations** in the left nav of the web app.
- Existing tasks, schedules, run history, and delivery settings are untouched.

The new name better reflects what these do and where they're headed. Today an Automation runs your Adapt query on a schedule — recurring or once at a future time — and delivers the results to a Slack DM, a Slack channel, or a new chat. Describe it in plain English and Adapt sets it up.

```
Every Monday at 9am, summarize last week's closed deals and post it to #sales.
```

See [Automations](/features/automations) for the full reference.
